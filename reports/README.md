# Reports

- Contains the current Stage 2 Word report, generated metrics/results, and figures.
- `scripts/build_report.py` generates the Word report; pipeline scripts generate the metrics.
- Do not hand-edit files under `generated/`; regenerate them from their source scripts.
- `data_dictionary.csv` is a byte-identical compatibility copy for the legacy v1 consistency reader; its archived source is `archive/data_dictionary.csv`.
- Hand-authored technical documentation is maintained under `docs/`.
