# UCI-697 ML protocol

- Dataset: UCI-697; target `Target`; seed `20261105`.
- Split: stratified 60/20/20; train only for fitting and 5-fold tuning; validation only for model/threshold/calibration selection.
- Test access: `ALLOW_TEST_EVAL=1`, one-shot loader with JSONL use log; must be run only after model and threshold selection.
- Preprocessing (imputation, one-hot encoding, scaling) is fitted inside each train-only CV pipeline.
- Main feature set (24): Admission grade, Age at enrollment, Application mode, Application order, Course, Curricular units 1st sem (approved), Curricular units 1st sem (credited), Curricular units 1st sem (enrolled), Curricular units 1st sem (evaluations), Curricular units 1st sem (grade), Curricular units 1st sem (without evaluations), Daytime/evening attendance, Displaced, Educational special needs, Father's occupation, Father's qualification, Gender, International, Marital status, Mother's occupation, Mother's qualification, Nacionality, Previous qualification, Previous qualification (grade).
- Main features use only `available_at` T0/T1_known; excludes semester 2, Debtor, Tuition fees up to date, Scholarship holder, Unemployment rate, Inflation rate, GDP. Timestamps for the macro variables are unverified.
- P1 sensitivity adds the excluded feature group separately; it is not used for the final model. A separate P1 run drops `Course` because it is a Portuguese program code with no NTU IT meaning.
- Selected early-warning model: `XGBoost` (three-class).
- Calibration chosen on validation after fitting on train OOF predictions: `uncalibrated`.
